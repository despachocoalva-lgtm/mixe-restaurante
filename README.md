# Mixe Restaurante

Sistema digital para restaurantes: menú, pedidos por mesa, club de clientes y fidelización.

## Desarrollo

Este es el repositorio principal de Mixe. Se desarrollará y desplegará en Vercel, inicialmente con su dirección de pruebas y posteriormente con un dominio propio.

## Primera publicación

El prototipo HTML está en `index.html` en la raíz del repositorio. Este commit activa un nuevo despliegue automático mediante la integración de GitHub con Vercel.
